# go-terraforming-mars

Study project//

This project is a personal web-based implementation of the board game **[Terraforming Mars](http://www.fryxgames.se/games/terraforming-mars/)** by Jacob Fryxelius.

### 💡 Motivation
This repository is a technical study aimed at exploring complex state management and game logic in Golang. The primary goal was to create a stable, bug-free digital engine as a personal alternative to existing digital ports.
